# AGENTS.md

`ikigai-http` is the outbound HTTP-client module for the ikigai kernel: one endpoint per HTTP
method, gated by `urn:cap:net:*` capabilities, with the kernel's caching applied to HTTP.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Security reports go through [private vulnerability
  reporting](https://github.com/ikigai-rs/ikigai-http/security/advisories/new), never a public
  issue.
- Use American spelling (behavior, color, labeled, artifact).
